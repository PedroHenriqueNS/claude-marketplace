# Discovery description

> Default shape for a discovery or spike. A workspace file's own shape overrides this one. A discovery is bounded by a question, not by a deliverable — if the work has a known outcome, it is a project or an issue, not a discovery.

## Question

The one thing this discovery exists to answer. If it cannot be phrased as a question, it is not a discovery.

## Hypotheses

What we currently believe the answer might be. Listing more than one keeps the discovery honest.

## What to investigate

The concrete things to read, prototype, measure, or ask — enough that someone else could pick this up.

## Expected output

What comes out of this: a recommendation, a spike branch, a benchmark, a decision record. Include the stopping condition — what makes this done rather than merely paused.
